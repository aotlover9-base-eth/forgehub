- **Date/time:** 2026-11-22 (Asia/Kolkata)
- **WP:** B2 (Phase B - CLI improvements). Fixes audit F1, F9, F14 (docs part); F7 assessed and left (see section 3).
- **Status:** Done, pending CI verification of this commit's head (local cargo blocked by the sandbox write fault).

## 1. What landed

- **Grouped top-level help.** `fg --help` now groups the 33 commands under **Library** (init, record, run, list, show, search, tag, rename, delete, edit, parameterize, clone, import, export, analyze, stats, backup, restore), **Cloud** (login, logout, whoami, push, pull, status, diff, fork, remote, update), **Safety** (trust, cache) and **Tools** (doctor, alias, completions, ui), via clap `next_help_heading` on the first variant of each group (plus the two group members declared later in the enum, update and cache; clap merges same-name headings). The root help footer names the concept topics.
- **`fg help <topic>`** (new module `crates/forge-cli/src/topics.rs`): explainers for `alias`, `trust`, `hash-pinning`, `yes`, `offline` (aliases `hash`, `-y`), intercepted in `main` before clap parses - a topic name is never a command, so clap keeps owning `fg help <command>` and nothing can be shadowed. Content states the shipped safety model exactly (full card, typed yes, hash-change diff, exit 2 without a TTY, the `fg` builtin collision and `jobs-fg`). Tests pin the invariants (each topic resolves, is substantive, contains no em dash; the trust/yes/offline texts state their safety invariants; command names do not resolve as topics).
- **Completions completed.** The dynamic completer now offers local snippet names **and cached `owner/name` references** (`merge_candidates`: union, prefix filter, sort, dedup - unit-tested), and it is wired to the arguments that take cloud references but had no completer: `push <name>`, `pull <reference>`, `fork <reference>`, `status [name]`, `diff <name>`, `trust` references (shorthand, add, revoke), and `remote show/delete/visibility`. The completion scripts themselves are generated by the existing dynamic engine, so bash/zsh/fish all pick this up without script changes.
- **Docs (F14):** `docs/cli-reference.md` documents the grouped help, the topics and the completion behaviour.
